Kebijakan Privasi

Terakhir diperbarui: 12 November 2026

Kebijakan Privasi ini menjelaskan bagaimana RISLY Money Manager ("kami") mengumpulkan, menggunakan, dan melindungi informasi pribadi Anda saat menggunakan aplikasi ini yang diakses melalui domain https://risly.pages.dev.

Penting: RISLY Money Manager adalah aplikasi Progressive Web App (PWA) yang berjalan sepenuhnya di browser Anda. Data keuangan utama disimpan secara lokal di perangkat Anda (IndexedDB dan localStorage), bukan di server kami. Kami tidak memiliki server backend yang menyimpan data transaksi Anda.

1. Informasi yang Kami Kumpulkan

Jika Anda memilih untuk masuk menggunakan Google Sign-In, kami hanya menerima informasi dasar dari akun Google Anda melalui Firebase Authentication, meliputi:

  • Nama lengkap
  • Alamat email
  • Foto profil (URL gambar profil)

Informasi ini digunakan hanya untuk mengidentifikasi dan memverifikasi identitas Anda saat masuk, serta menampilkan profil di dalam dasbor aplikasi. Kami tidak menyimpan data ini di server kami.

2. Data Keuangan & Penyimpanan Lokal

  • Semua data transaksi, akun, kategori, anggaran, catatan, dan target keuangan disimpan secara lokal di perangkat Anda melalui IndexedDB dan localStorage.
  • Foto struk disimpan sebagai blob di IndexedDB (tidak sebagai base64 di dalam data workspace).
  • Jika Anda mengatur PIN, data lokal di-enkripsi at-rest menggunakan AES-GCM 256-bit dengan kunci yang di-derive dari PIN (PBKDF2-SHA256, 310.000 iterasi). Kunci enkripsi hanya ada di memori aplikasi dan tidak pernah disimpan ke disk.
  • Sesi login disimpan di sessionStorage + metadata IndexedDB (tidak ada cookie sensitif). Token Google Drive tidak disimpan di cookie yang bisa dibaca JavaScript.

3. Sinkronisasi Cloud & Ruang Keluarga (Opsional)

  • Sinkronisasi cloud melalui Firebase Realtime Database adalah fitur opsional dan hanya aktif jika Anda mengonfigurasinya sendiri.
  • Data yang di-sinkronkan ke Firebase meliputi data workspace (JSON), bukan file foto struk asli.
  • Berbagi keluarga dilakukan melalui kode undangan. Pemetaan keanggotaan disimpan di cloud agar akun yang sama di perangkat berbeda masuk ke rumah tangga yang sama.
  • Anda dapat berhenti menggunakan sinkronisasi cloud kapan saja melalui Pengaturan aplikasi.

4. Google Drive (Opsional)

Google Drive hanya digunakan untuk login dan backup manual (file JSON terenkripsi ke folder appDataFolder, maksimal 10 backup terbaru). Tidak ada sinkronisasi otomatis ke Google Drive. Token Google Drive tidak disimpan di cookie.

5. Perlindungan & Keamanan Data

  • Kami TIDAK AKAN PERNAH menjual, menyewakan, atau membagikan informasi pribadi maupun data keuangan Anda kepada pihak ketiga untuk keperluan pemasaran.
  • PIN minimal 6 angka (maksimum 8) dengan hashing PBKDF2-SHA256.
  • Login throttling eksponensial diberlakukan setelah beberapa kali gagal berurutan.
  • Auto-lock benar-benar menghapus kunci enkripsi dari memori.
Peringatan: Jika Anda lupa PIN dan tidak memiliki backup terenkripsi (.risly.enc) atau file JSON, data keuangan Anda tidak bisa dibuka kembali dan hilang permanen. Tidak ada mekanisme "lupa PIN" yang bisa membuka data terenkripsi karena kami tidak menyimpan kunci enkripsi di server.

6. Hak & Penghapusan Data

Anda berhak untuk berhenti menggunakan aplikasi kapan saja. Untuk menghapus data, hapus aplikasi/PWA dari perangkat Anda dan hapus data penyimpanan browser (cache, IndexedDB, localStorage). Anda juga dapat menghubungi pengembang melalui email untuk pertanyaan privasi data.

7. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan diberitakan melalui aplikasi atau halaman ini, serta tercantum tanggal pembaruan terbaru di atas.

8. Hubungi Kami

Jika Anda memiliki pertanyaan mengenai Kebijakan Privasi ini, silakan hubungi pengembang aplikasi melalui email yang tercantum di aplikasi atau repositori GitHub resmi.
